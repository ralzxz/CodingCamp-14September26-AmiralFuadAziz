# 💰 Expense & Budget Visualizer

Aplikasi web sederhana untuk mencatat pengeluaran harian dengan visualisasi chart dan manajemen kategori.

## ✨ Fitur Utama

### Fitur Wajib
- ✅ **Form Input** - Tambah pengeluaran (nama, jumlah, kategori)
- ✅ **Daftar Transaksi** - List pengeluaran dengan tombol hapus
- ✅ **Total Saldo** - Perhitungan otomatis total pengeluaran
- ✅ **Grafik** - Pie chart distribusi pengeluaran per kategori

### Fitur Tambahan
- ✅ **Custom Kategori** - Tambah, edit, dan hapus kategori sendiri
- ✅ **Spending Limit** - Notifikasi visual saat melebihi batas
- ✅ **Dark/Light Mode** - Toggle tema gelap/terang

## 🛠️ Teknologi

- HTML5
- CSS3 (Flexbox, Grid, CSS Variables)
- Vanilla JavaScript (ES6+)
- Chart.js
- Local Storage

## 📁 Struktur Folder

```
├── index.html          # Halaman utama
├── css/
│   └── style.css      # Styling
├── js/
│   └── app.js         # Logic aplikasi
└── .kiro/             # Kiro config (wajib untuk submission)
```

## 🚀 Cara Pakai

1. Buka `index.html` di browser
2. Tambah transaksi dengan mengisi form
3. Lihat total dan grafik ter-update otomatis
4. Set spending limit (opsional)
5. Toggle dark mode dengan klik tombol 🌙

## 💾 Penyimpanan Data

Data disimpan di Local Storage browser. Data akan tetap ada meskipun browser ditutup.

## 📱 Responsive

Aplikasi bisa digunakan di:
- Mobile (320px+)
- Tablet (768px+)
- Desktop (1024px+)
